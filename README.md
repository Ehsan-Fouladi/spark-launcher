# ⚡ Spark Launcher

**A fast, lightweight, and modern application launcher for Windows, built with Rust and Slint.**

Spark Launcher is a Windows desktop application inspired by [Flow Launcher](https://www.flowlauncher.com/). It aims to provide a simple and efficient way to access applications and launch items through a clean, keyboard-driven interface.

## ✨ Overview

Spark Launcher focuses on speed, simplicity, and a clean user experience.

Built with Rust for performance and reliability, and Slint for its modern desktop user interface.

## 🛠️ Tech Stack

- **[Rust](https://www.rust-lang.org/)** — Core application logic and performance.
- **[Slint](https://slint.dev/)** — Cross-platform declarative UI framework.

## 🎯 Project Goals

- Fast application launching.
- Keyboard-driven interaction.
- Minimal and modern user interface.
- Lightweight resource usage.
- Native desktop experience on Windows.

## 🚀 Getting Started

### Prerequisites

- Windows
- [Rust](https://www.rust-lang.org/tools/install)
- Cargo

### Build and Run

Clone the repository:

```bash
git clone <repository-url>
cd spark-launcher
```

Run the application:

```bash
cargo run
```

Build a release version:

```bash
cargo build --release
```
